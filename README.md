# Java Backend Course 2026

Репозиторий с лабораторными работами по курсу Java Backend.

## Лабораторная работа №1

Вариант 23: чтение значений `type` из CSV, получение уникальных
типов с помощью `HashSet` и запись результата в файл.

Также реализованы CRUD-операции для персонажей в CSV.

### Сборка и запуск

```bash
mvn clean package
java -jar lab-1/target/lab-1-1.0.0-SNAPSHOT.jar
```

Результат основного задания сохраняется в `lab-1/types.txt`.
